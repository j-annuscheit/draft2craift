2) Seed instead of total draft

shared/services/agentic/workers/maps/seed/seed_from_outline.py
def run(ctx, step, projected):
    _ = ctx, step
    root_label = str(projection_get(projected, "state.map_seed.root_label", "") or "Mindmap")
    outline = dict(projection_get(projected, "state.map_outline", {}) or {})
    focus = dict(projection_get(projected, "state.map_focus", {}) or {})
    spec = build_seed_spec(root_label=root_label, outline=outline, focus=focus)
    markdown = render_markdown(spec)
    stats = spec_stats(spec)
    value = {
        "markdown": markdown,
        "mode": "mindmap",
        "root_label": root_label,
        "version": 1,
        "stats": stats,
        "reason": "seed_from_outline",
    }
    return StepOutcome(value=value, meta={"nodes": int(stats.get("nodes", 0) or 0), "edges": int(stats.get("edges", 0) or 0)})
This part replaces the previous all-in-one draft idea. First comes a safe, parsable seed. Then it is expanded.

3) LLM really only for small suggestions

    frontier = dict(projection_get(projected, "state.map_frontier", {}) or {})

    ...
    prompt = (
        "You are expanding an existing mind map.\n"
        "IMPORTANT:\n"
        "- Only create DIRECT children for exactly ONE existing parent.\n"
        "- No new complete mind map.\n"
        "- No explanations outside of the JSON.\n"
        "- Only use terms that are supported by the evidence.\n"
        ...
    )
    try:
        raw_text = str(ctx.tools.call("llm.generate", prompt=prompt) or "")
    except Exception as exc:
        return StepOutcome(
            value={"raw_text": "", "reason": "llm_error", "error": str(exc)},
            meta={"prompt_chars": len(prompt), "snippet_count": len(snippets)},
        )
    reason = "ok" if str(raw_text or "").strip() else "empty_response"
    return StepOutcome(value={"raw_text": raw_text, "reason": reason}, meta={"prompt_chars": len(prompt), "snippet_count": len(snippets)})

This is intentionally narrowly defined: one parent, few evidence snippets, small JSON. This makes even smaller models much more controllable.

6) Finalization and Emit

shared/services/agentic/workers/maps/render/emit_result.py
def run(ctx, step, projected):
    payload = dict(projection_get(projected, "state.map_result", {}) or {})
    validation = dict(projection_get(projected, "state.map_validation", {}) or {})
    markdown = str(payload.get("markdown", "") or "")
    if markdown:
        ctx.tools.call("canvas.open_text", text=markdown, title="Mindmap")
    result_payload = {"markdown": markdown, "mode": "mindmap", "stats": dict(validation.get("stats", {}) or {})}
    return StepOutcome(
        value=result_payload,
        updates={"result.markdown": markdown, "result.meta": result_payload},
        stop=True,
        meta={"markdown_chars": len(markdown)},
    )

The terminal step is deliberately small. It no longer re-renders, it no longer executes any content-related business logic and it immediately ends the run afterwards.

7) Think of Graph Legacy separately

If you still see names like mindmap.ensure_connected_graph.v1 or mindmap.expand_map_depth.v1 in the code, these belong primarily to the graph workflow today. They are no longer the productive mind map main path.

For new mind map work, you should therefore first look in workers/maps/source, seed, frontier, validate, apply and render, not in the older graph/legacy runners.
